# CueCraft

CueCraft is an offline-first teleprompter for recording voiceovers against existing video.

The app uses a standalone HTML file and needs no build step, account, or server. Launch with `index.html` in a modern desktop browser.

## Status

Initial repository setup. The first application release is being prepared in a feature branch.

## Privacy

Video and imported scripts remain in your browser; CueCraft does not upload them. Keep confidential recordings and scripts out of this public repository.

## Roadmap

- Timed reading line, editable cues, import/export and video sync
- Microphone recording and take management
- Export replacement audio and composed video
- Optional local AI assistance
